# Mobius — Core Context

## General Principles
- **Think Before Coding**: Always clarify requirements and edge cases.
- **Simplicity First**: Avoid over-engineering and unnecessary abstractions.
- **Surgical Changes**: Minimize side effects and preserve context.
- **Goal-Driven Execution**: Ensure the project builds and tests pass.

## Universal Workflow
1. **Brainstorming**: Clarify user stories and success criteria.
2. **Planning**: Map out file changes and data contracts.
3. **TDD**: Write tests before or alongside implementation.
4. **Debugging**: Perform root cause analysis for any issues.
5. **Review**: Self-review for architecture, performance, and clean code.
