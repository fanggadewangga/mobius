# iOS Architecture

1. **MVVM**: The standard for SwiftUI projects.
2. **Coordinator Pattern**: For complex navigation logic (optional).
3. **Services / Repositories**: Abstract networking and persistence.
4. **Dependency Injection**: Use protocols and initializer injection.

"Separation of concerns leads to testability."
