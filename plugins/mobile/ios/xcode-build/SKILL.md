# iOS Xcode & Build System

1. **Info.plist**: Be careful when adding permissions or configuration.
2. **Swift Package Manager (SPM)**: Preference over CocoaPods if possible.
3. **Build Settings**: Do not modify unless necessary.
4. **Targets**: Understand the difference between App, Tests, and Framework targets.

"Xcode project files are XML beasts. Handle with care."
