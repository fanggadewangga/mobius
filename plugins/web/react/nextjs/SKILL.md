# Next.js Patterns

1. **App Router**: Use folder-based routing in the `app/` directory.
2. **Server Actions**: Use for mutations (form submissions, etc.) to handle logic on the server.
3. **Middleware**: Use for edge-level logic like auth checks or rewrites.
4. **Metadata API**: Use for SEO and social sharing tags.

"The full-stack React framework."
