# TanStack Router Patterns

1. **Type-Safe Navigation**: Leverage generated types for routes and params.
2. **File-Based Routing**: Organise routes using the file system (optional but recommended).
3. **Pending UI**: Use `pendingComponent` for loading states.
4. **Error Boundaries**: Use `errorComponent` per route.

"Type-safe routing for React and friends."
