# Web Debugging & Root Cause Analysis

1. **Hydration Errors**: Check for mismatches between server-rendered and client-rendered HTML.
2. **Network Issues**: Use DevTools Network tab to inspect payload and headers.
3. **State Debugging**: Use React/Vue DevTools to inspect current state and props.
4. **Console Logs**: Look for errors, warnings, and performance bottlenecks.

"Reproduce, isolate, and fix."
