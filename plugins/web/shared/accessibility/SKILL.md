# Web Accessibility (A11y)

1. **Semantic HTML**: Use `<nav>`, `<main>`, `<header>`, `<footer>`, and `<button>` correctly.
2. **ARIA Roles**: Use ARIA attributes only when semantic HTML is insufficient.
3. **Contrast**: Ensure high contrast for text and interactive elements.
4. **Keyboard Navigation**: All interactive elements must be reachable via Tab.

"Design for everyone."
