# Vite Configuration

1. **Aliases**: Define path aliases (e.g., `@` for `src/`) for cleaner imports.
2. **Plugins**: Use Vite plugins for specialized needs (e.g., `unplugin-vue-components`).
3. **Optimizations**: Configure `build.rollupOptions` for bundle optimization.
4. **Environment**: Use `import.meta.env` to access environment variables.
