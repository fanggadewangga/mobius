# Nuxt Patterns

1. **Pages & Layouts**: Use the directory-based structure for routing and shared UI.
2. **Data Fetching**: Use `useFetch` for simple GET requests and `useAsyncData` for complex logic.
3. **Auto-imports**: Leverage Nuxt's auto-import feature for components and composables.
4. **Modules**: Use Nuxt modules to extend functionality (e.g., `@nuxtjs/tailwindcss`).
